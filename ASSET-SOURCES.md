# Asset sources and licenses

- Display face: Barlow Condensed ExtraBold, SIL Open Font License 1.1. License: `assets/fonts/OFL-BarlowCondensed.txt`. Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- Mono face: JetBrains Mono Regular, SIL Open Font License 1.1. License: `assets/fonts/OFL-JetBrainsMono.txt`. Source: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
- Orbit and YouTube brand paths: Simple Icons, embedded from its SVG icon files at https://github.com/simple-icons/simple-icons/tree/develop/icons (Python, JavaScript, TypeScript, React, Next.js, Node.js, Express, MongoDB, MySQL, Git, GitHub, Figma, YouTube). Java and Gymnasium remain text chips because Simple Icons has no matching icon file in the selected set.
- LinkedIn and email symbols are inline text/envelope marks. No external icon assets are loaded.
- Portraits: the original RGBA files `assets/id.png` and `assets/right_pointing.png` are embedded byte-for-byte into the SVGs; no masks or redraws are applied.
